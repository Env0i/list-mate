# list-mate 产品路线图 — 2026 Q2-Q3

## 北极星指标
**每日打开记录 ≥ 1 次** — 当用户习惯性地打开 App 更新进度时，说明工具真正解决了问题。

当前基线：0（无工具）
季度目标：连续使用 30 天

---

## 🟢 Now — MVP（2026-05 月）

三端同步开发，以 H5 Web 为主要验证形态。

| 项目 | 用户问题 | 成功指标 | 状态 | ETA |
|------|---------|---------|------|-----|
| 后端 API | 无数据服务 | /docs 全部端点可用 | 未开始 | 3天 |
| Bangumi 搜索 | 手动输入太累 | 搜索→自动填充→保存 流程闭环 | 未开始 | 同 API |
| 移动端作品库 | 不知道看了什么 | 可浏览/筛选/搜索所有作品 | 未开始 | 5天 |
| 移动端进度更新 | 忘记看到哪了 | 一键更新进度，时间线可查 | 未开始 | 同作品库 |
| 游戏多配置 | 模组/整合包无记录 | 创建配置+上传 mod 清单 | 未开始 | 同详情页 |
| 统计 | 看不到数据全貌 | 仪表盘显示分类/状态分布 | 未开始 | 2天 |
| 管理后台 | Web 端便捷管理 | Element Plus 增删改查 | 未开始 | 3天 |
