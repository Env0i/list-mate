## ❌ 不做的（明确排期外）

| 需求 | 理由 |
|------|------|
| 内置阅读器/播放器 | 范围过大，与"纯记录"定位不符 |
| 社交/好友 | 个人工具不需要 |
| 多用户/账号 | SQLite 限制，单机工具 |
| AI 功能/推荐 | 对当前问题无帮助 |
| Uni-app 原生编译 | 个人 H5 够用，省去 Apple 开发者费用 |
| 管理后台 | 单用户不需要，前端 CRUD 已覆盖 |
