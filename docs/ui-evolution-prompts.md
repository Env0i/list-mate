# Zace UI 进化路线 — 设计工具提示词集

> 用法：把「全局上下文」作为对话开头（或系统提示）粘贴给设计工具，再逐条投喂方向提示词。
> 若工具支持多模态，**同时附上对应页面的真实截图**（浏览器截图即可），生成的方案会贴合现状得多。
> 每条提示词都写了验收清单——拿它对照产出，不达标就追加追问。

---

## 全局上下文（每次对话开头先贴这段）

```
你是 Zace（个人 ACGN 收藏管理应用）的资深 UI/UX 设计师。
产品定位：记录动漫/小说/漫画/游戏的进度与评价，核心情绪是"集换式卡牌收藏册"——
用户是收藏家，每部作品是一张卡牌。

既有设计语言（必须延续，不要推翻）：
- 隐喻：抽卡图鉴 / 集换卡册。作品卡 = 卡牌（多层边框、四角装饰、全息闪光 hover、
  发牌入场动画），状态 = 印章戳记（微旋转），进度 = EXP 经验条（带流光）。
- 色彩：暖白卡册纸背景 #F7F5F0（暗色主题为暖黑 #16130F，保持暖色温）；
  品类四色——动漫 #FF1A5E / 小说 #3366FF / 漫画 #00CC66 / 游戏 #FF7A00；
  主操作色为能量橙 #FF6B35。
- 字体：DM Sans + Noto Sans SC。圆角 6/10/16px 三档，阴影极轻。
- 双主题（亮/暗，暗色为纯变量覆盖）、双视口（桌面 ≥768px 顶部导航，移动 <768px 底部 Tab）。
- 概览页摘要卡均为"数字+标签+左侧色条"语言。

输出要求：高保真页面设计稿；每页给出空状态/加载态/错误态/数据满载态四种状态；
亮暗双主题；标注设计令牌（色值/字号/间距）与命名。
```

## 方向一：收藏列表页（高频主页面）

```
任务：打磨 Zace 的收藏列表页（第一屏）。

现状：页头为「收藏 + 数量 | 主题按钮」一行，「排序下拉 + 搜索框」一行；
品类 Tab（全部/番剧/小说/漫画/游戏，选中带品类色圆点）；
状态筛选 chips 行（可横滑）；标签筛选行；卡牌网格（桌面 3-5 列，移动 2 列）。
卡牌：封面区（无封面用品类渐变兜底）+ 右上角印章状态戳 + 底部 EXP 条
（含 −1/+1 快捷进度圆钮）+ 标题 + 品类徽章。

请优化：
1. 卡牌信息层级——收藏家扫一眼想知道"进度差多少"，EXP 条与数字的对比是否够？
2. 品类 Tab 与状态筛选的视觉关系（两层筛选易混淆，如何用间距/形态区分主次）。
3. 长列表（100+ 卡）的浏览节奏：是否需要吸顶筛选、回到顶部。
4. 空状态已有一对引导按钮，给出更符合卡册隐喻的空状态插画方向（如空卡册页）。

验收：不破坏卡牌隐喻与品类四色；移动端 375px 两列不拥挤；
筛选吸顶后不遮挡卡牌 hover 闪光效果。
```

## 方向二：作品详情页

```
任务：打磨作品详情页（收藏家停留最久的页面）。

现状结构：封面卡（左）+ 信息卡（标题/品类/状态印章/标签，右）→ 个人追踪卡
（优先度/进度 EXP 条/评分/评价）→ 历史卡（按天分组：今天/昨天/日期头的操作时间线）→
（游戏类）配置区。编辑走模态对话框。

请优化：
1. 信息卡的首屏叙事：封面 + 状态印章 + 关键数字（进度/评分）如何一眼成"这张卡的档案页"。
2. 历史时间线的可视化升级：在按天分组列表基础上，给"进度更新"加迷你趋势
   （如 3→4→5 的 sparkline），让成长可视化。
3. 游戏多配置的卡位设计（每配置一条进度条 + 状态）与主进度区的主次关系。
4. 编辑模态的字段分组与移动端单列滚动的节奏（两列表格 → 单列的分界）。

验收：历史区即使 20+ 条也不显冗长（考虑折叠/吸顶摘要）；
印章戳记与 EXP 条隐喻不变形。
```

## 方向三：统计仪表盘

```
任务：升级统计页为"收藏家的年度报告"气质。

现状：四张摘要卡（全部作品/进行中/已完成/本周活跃，数字+标签+左色条）；
品类分布条形；状态分布；评分等级分布（S/A/B/C）；操作时间线（按天分组，可切 Tab）。

请优化：
1. 摘要卡四张的信息主次——哪张该最大？（建议"本周活跃"作为习惯激励位）
2. 新增"月度活跃趋势"模块：最近 6 个月每月操作数的条形/热力表现，与现有
   左色条卡语言一致（不要引入外部图表库风格，用 CSS 条形+品类色）。
3. "藏品墙"模块方向：按评分 S/A/B/C 分区展示卡牌缩略，像卡册的珍贵页。
4. 数据为空时的各模块空状态（新用户第一天打开的样子）。

验收：不加新颜色（只用既有品类色+主色+中性色）；数字排版对齐现有摘要卡。
```

## 方向四：搜索添加页

```
任务：打磨 Bangumi 搜索添加页。

现状：大搜索框 + 类型筛选（全部/书籍/番剧/音乐/游戏，切换即实时重搜）；
结果为封面卡网格，卡上有类型徽章（品类色）与年份徽章；点击弹出确认对话框
（可改分类后入库）。

请优化：
1. 结果卡信息密度与封面占比的平衡（类型/年份徽章的位置与形态）。
2. "已收藏"标记：搜索结果中已在库中的作品应如何标识（避免重复添加）——
   给出角标/勾选态设计。
3. 确认对话框的信息分组（封面预览/分类/总量自动回填）与"看起来像把卡放进册子"的
   入库仪式感（如入库成功的卡牌入册动效方向）。
4. 搜索失败的错误态（网络异常）与重试入口。

验收：徽章不喧宾夺主（封面仍是主体）；确认对话框保持单列紧凑。
```

## 方向五：移动端专项（375px）

```
任务：移动端专项打磨。

现状：底部 Tab 五项（首页/搜索/＋悬浮/统计/标签）；页面顶部无全局栏，
主题切换在列表页头右侧（弹出三选：跟随系统/白天/黑夜）；
卡牌两列；详情页单列堆叠；触控目标已达 36px+。

请优化：
1. 底部 Tab 与悬浮 ＋ 的组合是否最优（对比：居中大按钮 vs 右下 FAB）。
2. 单手操作热区审计：高频动作（±1、编辑、切筛选）的拇指可达性。
3. 列表页头（标题/主题/排序/搜索）在移动端的层级压缩方案。
4. 手势机会：卡牌左滑出快捷操作（编辑/删除）是否值得做，给出利弊。

验收：不增加底部 Tab 数量；任何固定悬浮元素不遮挡内容与底栏。
```

## 方向六：暗色主题一致性

```
任务：审计并补全暗色主题（暖黑 #16130F 系）的细节一致性。

已知设计令牌：surface #201C17 / hover #2A251F / 文字 #F0EDE7 系 /
品类色与主色保持饱和不变。
已知风险点：组件内硬编码白色（toggle 圆点等——语义正确的保留）、
图片类内容在暗背景上的边缘处理、品牌 logo 反白。

请产出：暗色专项审计清单（逐组件：列表/详情/统计/搜索/表单控件/弹窗/Toast），
对每处给出"保留/微调"判断与色值建议；重点处理阴影体系
（亮色极轻阴影在暗色下如何改为描边+抬升）。
```

## 方向七：微交互与动效节奏

```
任务：为既有动效体系制定节奏规范并补齐缺失微交互。

既有：发牌入场（card-deal 0.45s 弹性）、印章盖章（stamp-in）、
EXP 流光（shimmer 2.5s 循环）、全息闪光 hover、页面切换 fade。

请优化：
1. 制定动效时长/缓动令牌表（入场/退出/悬停/反馈四类），统一现有多处不一致。
2. 补齐：±1 点击的 EXP 条增长反馈（数字滚动/条形过渡）、
   备份/还原成功的数据安全反馈动效方向、
   标签 chip 添加/移除的形变过渡。
3. 明确"少即是多"清单：哪些地方不要动画（表单输入、筛选切换）。

验收：动效只强化"收藏/成长"隐喻，不增加感知等待。
```

## 方向八（远期）：年度收藏报告页

```
任务：设计"年度收藏报告"页面（数据故事化，收藏家的仪式感页面）。

数据素材：品类分布、月度活跃趋势、评分分布、最评分作品、状态变迁
（今年看完 X 部）、标签 usage。

请产出：单页长图式报告设计（章节式：开篇→品类→节奏→高光→结语），
延续卡册隐喻（如"翻开今年的册子"），每章一个视觉锚点；
给出从统计页进入的入口形态与分享出去的封面帧设计。

验收：所有图表用既有品类色/主色/中性色；移动端长图滚动节奏（每屏一个章节）。
```

## 通用验收清单（每条提示词产出后逐项核对）

- [ ] 卡册/卡牌隐喻未被稀释，品类四色未引入新色相
- [ ] 亮/暗双主题均给出（且暗色用变量思路而非逐处改色）
- [ ] 四态齐全：空 / 加载 / 错误 / 满载
- [ ] 375px 与桌面均可用；触控目标 ≥36px
- [ ] 标注设计令牌（色值/字号/间距/圆角/阴影），可直接翻译成 CSS 变量
- [ ] 状态印章、EXP 条、发牌/盖章动效的隐喻没有被"通用后台风"取代
```
